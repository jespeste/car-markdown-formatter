# car-markdown-formatter
The cli tool `cat`, but for markdown in the terminal. Aptly named car.

## Goals
- Write `car <markdownfile>.md` and get a more properly formatted markdown out in the terminal. Either straight like cat, or a more fully fledged "viewer" that switches to the second view.
- `car` can be accessed anywhere, just like cat. It should be easily usable and accessable
